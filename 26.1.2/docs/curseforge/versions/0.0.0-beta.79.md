### Weapon Attack Speed Controls Animation Speed

Animation playback speed now scales with the weapon's attack speed attribute using PAC's SpeedModifier.

**Changes:**
- SpeedModifier adjusts animation speed based on `Attributes.ATTACK_SPEED`
- Old SpeedModifiers removed before adding new ones (no accumulation)
- Swords (1.6): animations play faster
- Axes (1.0): normal speed
- Full player model in first person (THIRD_PERSON_MODEL) with both arms visible
