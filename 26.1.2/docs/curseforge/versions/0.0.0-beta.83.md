<h2>v0.0.0-beta.83 — Mining Fix, Speed Control, Dynamic Arms</h2>

<h3>Fix</h3>
<ul>
<li><strong>Mining with off-hand weapon prevented</strong>: <code>shouldPreventMining()</code> now checks both main hand and off-hand for weapons.</li>
</ul>

<h3>Feat</h3>
<ul>
<li><strong>Animation speed from weapon attack speed</strong>: SpeedModifier scales playback speed based on <code>Attributes.ATTACK_SPEED</code>. Swords (1.6) play faster, axes (1.0) at normal speed.</li>
<li><strong>Dynamic arm visibility</strong>: Arms (THIRD_PERSON_MODEL) only visible during attack animations. Returns to vanilla first-person view when not attacking.</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li><code>ClientPlayerInteractionManagerMixin.shouldPreventMining()</code> — refactored to <code>isWeapon()</code> helper and checks both hands.</li>
<li><code>CombatAnimationController.getFirstPersonMode()</code> — now returns THIRD_PERSON_MODEL only when <code>isAttackAnimationPlaying()</code> is true, NONE otherwise.</li>
<li><code>handleAttackAnimation()</code> — adds SpeedModifier with weapon attack speed before triggering animation.</li>
</ul>
