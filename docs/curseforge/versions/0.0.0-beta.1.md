<h2>v0.0.0-beta.1 — Initial 26.2 Port</h2>

<h3>🚀 Port to Minecraft 26.2</h3>
<p>Dinamyc Combat has been ported to <strong>Minecraft 26.2</strong> / <strong>NeoForge 26.2.0.32-beta</strong>, starting from the stable 26.1.2 state (<code>1.0.5</code>).</p>

<h3>🛠 Changes</h3>
<ul>
<li><strong>Dependencies</strong> — <code>player_animation_core</code> <code>0.0.0-beta.1</code> and Cloth Config <code>26.2.155</code>.</li>
<li><strong>RangedWeaponItemMixin</strong> — <code>ProjectileWeaponItem.getProjectile</code> renamed to static <code>getHeldProjectile</code> in 26.2; the off-hand override for players is preserved with an <code>@Inject</code> at HEAD.</li>
<li><strong>PlayerEntityRangeMixin</strong> — target updated from <code>Player.getEntityInteractionRange()</code> to <code>entityInteractionRange()</code> (renamed in 26.2).</li>
<li><strong>Removed dead mixin</strong> — <code>EntityHitboxDebugRendererMixin</code> targeted the removed <code>LevelRenderer.renderHitbox</code> and was an empty stub.</li>
</ul>

<h3>✨ Features (from 1.0.5)</h3>
<ul>
<li><strong>33 weapon presets</strong> — one-handed, two-handed, dual-handed and pose animations.</li>
<li><strong>Hold-to-attack</strong> with alternating hands for dual wielding.</li>
<li><strong>First-person animation</strong> — full player model renders in first person.</li>
<li><strong>Configurable</strong> — full client-side config screen.</li>
</ul>
