### First-Person Weapon Animation Fix

First-person weapon animation now matches third person by combining BOTH arm rotation AND shoulder position — just like Better Combat.

**The problem we fixed:**

Third-person shows the full arm swing: the arm ROTATES at the shoulder AND the shoulder MOVES through space. Our earlier first-person code only captured the rotation. The weapon spun in place instead of swinging through an arc.

**How it works now:**

- **Arm bone position** (x/y/z shoulder movement) applied to the item in first person
- **Arm bone rotation** (yaw/roll/pitch) applied to orient the weapon
- **Tick 0 keyframes** added to all animations for smooth transitions (no sudden snaps)
- The weapon now moves through a full arc on screen: wind-up → strike → follow-through

**Changes:**

- Added tick 0 rightArm/leftArm keyframes to all animation JSONs for smooth transition from default pose
- FirstPersonItemRendererMixin now applies arm bone POSITION (x/y/z) in addition to rotation
- Position captures the shoulder movement during the swing, completing the full hand arc
- First-person weapon now matches third-person arm swing: rotation + shoulder position together reproduce the full motion
- Updated gradle.properties version format to match project conventions (0.0.0-beta.X)
- Added docs/WORKFLOW.md with development workflow documentation
- Added curseforge/ files for CurseForge release management
