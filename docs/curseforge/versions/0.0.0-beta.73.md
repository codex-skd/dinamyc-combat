### Fixed first-person weapon swing arc

Removed the arm bone position (model-space shoulder coordinates) from the first-person transform. The weapon now swings freely using only rotation-derived hand position.

**Changes:**

- fix: remove arm bone position from first-person mixin (was applying shoulder model-space coords to first-person item, anchoring it off-screen)
- fix: compute hand position from rotation only: sin(yaw)*arm_length for left-right, sin(pitch)*arm_length*0.6 for up-down
- Weapon now correctly swings from right to left through the full arc matching third person
