### Switched to PAC HANDS_ONLY mode with original Better Combat transforms

After extensive debugging with frame-by-frame logging, discovered that HANDS_ONLY_ARM was not reaching the keyframe rotation values (yaw peaked at 0.537 vs expected 0.956). Switched to PAC's HANDS_ONLY mode which uses the original Better Combat right_item bone transforms (position + rotation baked into JSON).

**Changes:**
- Switched from HANDS_ONLY_ARM (right_arm rotation) to HANDS_ONLY (right_item transforms)
- PAC now applies original Better Combat right_item values (position + rotation from JSON)
- Removed custom mixin computing hand position from arm rotation
- Weapon animation uses the same transforms as Better Combat third-person item positioning
- Zero custom mixins for first person
