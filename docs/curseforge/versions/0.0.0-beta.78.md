### Animation Speed Based on Weapon Attack Speed

Animation playback speed now scales with the weapon's attack speed attribute. Fast weapons (swords, daggers) play animations faster; slow weapons (axes, hammers) play them slower.

**Changes:**
- Animation speed now matches weapon attack speed via `triggerAnimation(animId, speed)`
- Swords (1.6): animations play 1.6x faster
- Axes (1.0): normal speed
- Pickaxes (1.2): 1.2x faster
- Full player model in first person (THIRD_PERSON_MODEL) with both arms visible
- Armor visible in all perspectives
