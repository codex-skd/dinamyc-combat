<h2>v1.0.0 - First Stable Release</h2>

<p>First stable release of Dinamyc Combat. All features are now production-ready with full first-person animation support, configurable arm visibility, and weapon speed scaling.</p>

<h3>Highlights</h3>
<ul>
<li><strong>33 weapon presets</strong> with unique attack patterns (slash, stab, slam, spin)</li>
<li><strong>First-person animations</strong> — full player model renders in first person during attacks</li>
<li><strong>Configurable arm visibility</strong> — toggle arms on/off in first person (<code>isShowingArmsInFirstPerson</code>)</li>
<li><strong>Weapon speed scaling</strong> — attack animations match weapon attack speed</li>
<li><strong>Hold-to-attack</strong> — continuous attacks while holding the button</li>
<li><strong>Off-hand mining prevention</strong> — weapons block mining in both hands</li>
</ul>

<h3>Fix</h3>
<ul>
<li><strong>Off-hand mining</strong>: weapons in the off-hand now prevent block mining correctly</li>
</ul>

<h3>New</h3>
<ul>
<li><strong>Client config option</strong> <code>isShowingArmsInFirstPerson</code> — show/hide arms during first-person attacks (default: true)</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li><code>CombatAnimationController.getFirstPersonMode()</code> — respects <code>ClientConfig.IS_SHOWING_ARMS_IN_FIRST_PERSON</code> config</li>
<li><code>handleAttackAnimation()</code> — <code>SpeedModifier(speed)</code> uses <code>Attributes.ATTACK_SPEED</code> for weapon-synced animation speed</li>
<li><code>shouldPreventMining()</code> — checks both main hand and off-hand via <code>isWeapon()</code></li>
<li>First-person view returns to <code>FirstPersonMode.NONE</code> when not attacking (vanilla view preserved)</li>
</ul>

<h3>Dependencies</h3>
<ul>
<li>Player Animation Core 1.0.0 (included)</li>
</ul>
