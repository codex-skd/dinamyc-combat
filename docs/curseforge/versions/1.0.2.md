<h2>v1.0.2 - Arm Visibility Fix &amp; Sweep Arc Effect</h2>

<h3>Fix</h3>
<ul>
<li><strong>Arm visibility toggle keeps animation running</strong>: setting <code>isShowingArmsInFirstPerson</code> to false no longer disables the first-person animation entirely. Arms become invisible but the weapon continues to animate normally.</li>
<li><strong>First-person enabled check</strong>: <code>isFirstPersonEnabled()</code> no longer depends on <code>IS_SHOWING_ARMS_IN_FIRST_PERSON</code> — <code>FIRST_PERSON_ANIMATIONS</code> config works independently.</li>
</ul>

<h3>New</h3>
<ul>
<li><strong>Sweep arc effect</strong>: vanilla-style sweep arc particle appears during attacks. Configurable via <code>isShowingSweepEffect</code>.</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li><code>CombatAnimationController.getFirstPersonMode()</code> always returns <code>THIRD_PERSON_MODEL</code> during attacks — arm visibility controlled via <code>FirstPersonConfiguration.setShowRightArm()</code>/<code>setShowLeftArm()</code></li>
</ul>
